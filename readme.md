# Linux the Game

Браузерный симулятор Linux-терминала с CRT-стилистикой.

## Реализованные команды

### Файловая система (виртуальная ФС с сохранением в localStorage)

| Команда | Функционал |
|---------|-----------|
| `ls` | Список содержимого директории. Флаги: `-a` (скрытые файлы), `-l` (детальный формат), `-la`. Метки `/` для директорий. |
| `cd` | Смена директории. Поддерживает: абсолютные пути (`/home/user`), относительные (`documents`), `..`, `../`, `.`, `~`, `~/`, `/`. Обновляет промпт. |
| `pwd` | Текущий рабочий путь. |
| `cat` | Вывод содержимого файлов. Несколько файлов за раз. Редирект: `>` (перезапись), `>>` (добавление). Экранирование HTML. |
| `mkdir` | Создание директорий. Флаг `-p` — создание промежуточных директорий. |
| `touch` | Создание пустых файлов. Обновление существующих. |
| `rm` | Удаление файлов. Флаги: `-r`, `-rf` (рекурсивно). Защита `/` и `/home/<user>`. |
| `cp` | Копирование файлов. Сохранение прав и владельца. |
| `mv` | Перемещение/переименование. Проверка same-file. Перемещение в директорию. |
| `echo` | Вывод текста. Кавычки `"` и `'`. Редирект: `>` и `>>`. Экранирование HTML. |

### Информация о системе (статический вывод)

| Команда | Функционал |
|---------|-----------|
| `whoami` | Текущий пользователь. |
| `hostname` | Имя хоста. |
| `uname` | Информация о системе (`Linux the Game 1.0 virtual x86_64`). |
| `date` | Текущая дата и время. |
| `df` | Использование диска. |
| `free` | Использование памяти (RAM/Swap). |
| `ps` | Список процессов. |
| `top` | Топ процессов по ресурсам. |
| `lsblk` | Блочные устройства. |

### Управление пользователями

| Команда | Функционал |
|---------|-----------|
| `login` | Вход по логину/паролю. State machine: `idle → waiting_for_username → waiting_for_password → idle`. AJAX-авторизация через `api/auth.php`. Приветствие на RU/EN. |
| `logout` | Выход из сессии. Сброс пользователя, пути, хоста. Восстановление ФС по умолчанию. |
| `useradd` | Регистрация. Интерактивный режим (4 шага) и `useradd <login> <email> <pass> <pass_confirm>`. AJAX через `api/auth.php`. |
| `adduser` | Полный аналог `useradd` (делегирование). |

### Утилиты

| Команда | Функционал |
|---------|-----------|
| `clear` | Очистка экрана терминала. |
| `help` | Список всех доступных команд (из `api/commands.php`). |
| `man` | Документация команд (из `api/man.php`). Кеширование. RU/EN. |
| `exit` | Сообщение о невозможности выхода (симулятор). |
| `gameinfo` | Информация о проекте в overlay. |
| `backupfs` | Восстановление ФС к состоянию по умолчанию. |

## Возможности терминала

- **Автодополнение (Tab):** команды и пути. Поддержка абсолютных, относительных и `~/` путей, включая `../`.
- **История команд:** навигация стрелками ↑↓, сохранение в `localStorage`.
- **Двуязычность:** RU/EN, переключение кнопками. Локализация сообщений и man-страниц.
- **Виртуальная ФС:** дерево директорий с правами, владельцами, содержимым файлов. Сохранение в `localStorage` и на сервер.
- **CRT-стилистика:** эффекты развёртки, glow, scanlines.
- **Промпт:** `user@host:path$` с обновлением при навигации.

## Технологии

- Frontend: jQuery 3.7.1, HTML/CSS
- Backend: PHP (Apache/XAMPP), MySQL
- Тесты: Jest (JS), PHPUnit (PHP)
- Шрифты: Press Start 2P

## Структура проекта

```
├── index.php              — главная страница
├── api/                   — PHP API (auth, fs, commands, man pages)
├── css/                   — стили
├── js/
│   ├── terminal.js        — ядро терминала (resolvePath, autocomplete, prompt)
│   └── commands/          — реализации команд (30 файлов)
├── db/schema.sql          — схема БД
├── resources/             — шрифты
├── tests/                 — тесты (Jest + PHPUnit)
├── composer.json          — PHP-зависимости
├── package.json           — JS-зависимости (Jest)
└── jest.config.js         — конфиг Jest
```

## Команды без реализации (есть man-страницы)

Около 70 команд имеют документацию в `api/man_en/` и `api/man_ru/`, но не реализованы в терминале. При вводе выводится «команда не найдена». Полный список доступен через `man <команда>`.
